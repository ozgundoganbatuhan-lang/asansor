# Public Document Templates

Bu klasörde servis firmaları ve müşteriler için kullanılabilecek PDF şablonları bulunmaktadır:

- **teklif-sablonu.pdf** — Asansör bakım hizmetleri için teklif şablonu. Fiyat, hizmet kapsamı ve hukuki bilgileri içerir.
- **sozlesme-sablonu.pdf** — Asansör bakım sözleşmesi şablonu. Tarafların sorumlulukları, süresi ve özel hükümler yer alır.

Bu dosyalar uygulama içinden doğrudan müşteri portalı üzerinden görüntülenebilir ve indirilebilir.
